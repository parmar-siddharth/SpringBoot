Spring Boot Fundamentals

This repository contains small Spring Core and Spring Boot fundamentals/revision examples created while learning the basics through Spring Profiles.

Topics included:

- Spring Core: IoC, beans, ApplicationContext, dependency injection, scopes, and lifecycle
- Spring vs Spring Boot, starters, embedded Tomcat, and auto-configuration
- IoC, beans, component scanning, and dependency injection
- Stereotype annotations, `@Bean`, scopes, and bean lifecycle
- `application.properties`, `@Value`, and profiles (`dev` / `prod`)
- Basic controller mappings and a high-level Spring MVC request flow

The examples are intentionally small and focused on revision. The accompanying PDF notes include Hinglish and English explanations, runnable snippets, common errors, and interview-ready answers.
